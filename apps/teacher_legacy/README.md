# edaya_teacher_legacy

Archived four-tab teacher classroom app (Calendar / Evaluations / Teaching / Report cards) kept as a fallback after the Accueil cutover.

Production Teacher is `apps/teacher` (`edaya_teacher`, `com.softilab.edaya.staff`).

```bash
melos run run:teacher:legacy:local
melos run run:teacher:legacy:staging
melos run screenshots:teacher:legacy:review
```
